# Updates

Open the main window's **More > Updates...** menu to check for an update. The window shows the installed version, an available version when found, its status and **What's new** notes when provided.

An update is offered only when a compatible published release is available. Opening the window or checking does not install an update or restart the app.

## Check, Download And Install

1. Choose **Check for updates** and read the result. If an update is offered, review its notes. **License terms** lets you read its terms before downloading.
2. Choose **Download update**. The progress display shows the download, and WhirlyTask checks the downloaded files before offering installation. Use **Cancel check** or **Cancel download** to stop the corresponding operation.
3. Finish or stop playback and recording, and close any open settings dialog. Use **Save** or **Ctrl+S** for your workflow and wait for confirmation.
4. Choose **Install and restart** when you are ready. Accept the offered license terms if required. WhirlyTask retains its editing session before closing and restarting with the update.

Downloading leaves the installed app in place. You choose when to install. If the workspace cannot be retained, the app stays open and installation does not proceed.

## License Terms

The **License terms** button is a preview. Reading or closing that preview does not accept anything.

If you have not accepted the offered license version and text, installation opens a separate terms dialog. Read it, select **I accept these license terms**, then choose **Accept and install**. The checkbox starts unchecked. Choose **Cancel** to decline and keep using the installed version.

Changed terms require a new explicit acceptance. Previously accepted matching terms do not need another confirmation for each app update.

## Startup Checks

**Check for updates on startup** controls a quiet check after startup once the app is idle. An available update is indicated in the main menu as **Updates... (Update available)**. Turn this option off to check manually.

Startup checks do not download, install or restart automatically. Those actions still require your choices in the Updates window.

## App And Recognition Components

Updates can include the app, OCR support and image recognition support. Unchanged runtimes and models are reused, so an app-only change does not require downloading the recognition models again. A release that changes those parts includes the required downloads.

Your Library, preferences and workflow files are kept. The editing session is restored after restart; unsaved edits retain their unsaved state. Session recovery does not replace saving a workflow file.

## Complete Installation

The complete installer requires an empty destination folder. Choose a separate empty folder when installing a complete copy. Use the in-app Updates window to update an installed copy. Your saved app data is kept.
