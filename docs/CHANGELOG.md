# Documentation changes

## Current graph-editor refresh — 23 October 2026

This is a documentation refresh, not an app version number.

- Replaced list-editor instructions with connected steps, blocks, selection, Step IDs and the current inspector.
- Updated recovery and saving: reopening the editor is different from applying a playback draft or saving a named library item.
- Replaced Sequence Value terminology with Variable, including Starter Variable, explicit Insert/Replace, Text/Math and Reset Variable.
- Added the current recognition reference: multilingual local OCR, character filters, Smart/Pixel image modes, If Image Click and If Pixel.
- Updated watcher names, configuration and examples, including Variable Watcher in the Variable tab.
- Updated reusable blocks to the selection-based save workflow and `.prm` files.
- Reworked navigation, examples and troubleshooting; retained older page paths as compatibility routes.

Descriptions are checked against the current editor and runtime source. Older releases can have different labels or behavior.
