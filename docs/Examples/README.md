# Examples

These patterns show connected workflows. Replace targets, areas, names, and stable Step IDs with values from your own workflow.

| Example | Pattern |
| --- | --- |
| [Counter limit](Counter-Limit.md) | Bound retries with a Starter Variable and If Variable |
| [Basic loop](Basic-Loop.md) | Repeat while a valid condition matches |
| [Watcher recovery](Watcher-Recovery.md) | Stop affected work, recover, then start at an explicit step |
| [Notifications](Notification-System.md) | Report progress and confirm completion before sending messages |

Build one action at a time, check Editor Issues, and test with Play. Use Save to keep the file; automatic recovery also retains the editing session across restart.

See [Steps](../Steps/README.md), [Guides](../Guides/README.md), and [reusable premade blocks](../Guides/Reusable-Premade-Blocks.md).
