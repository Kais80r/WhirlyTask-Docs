# Press Key

Presses and releases a selected keyboard key for **Hold seconds**.

Use the **Key** helper to choose a supported key name instead of guessing its spelling. The keystroke goes to the active application, so focus the intended window before using it.

```text
Start -> Focus Window: Report -> Press Key: Enter / 0.05
```

Use a short positive hold for a normal tap and a longer duration only when the application needs it. This step is for key input, not arbitrary text entry. To put text on the clipboard, use [Set Clipboard](Set-Clipboard.md), then send the appropriate application input separately.

Related: [Focus Window](Focus-Window.md) and [Press Mouse Button](Press-Mouse-Button.md).
