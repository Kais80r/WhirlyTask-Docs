# Set Cursor Position

Moves the cursor to **Position** without clicking.

Use the screen-point helper to choose a physical desktop location. On multiple monitors, valid coordinates can be negative. Moving or resizing a window later can make a saved position point somewhere else.

```text
Start -> Set Cursor Position: 640,360 -> Press Mouse Button: M1 / 0.05
```

A fixed position does not identify an object. Prefer [Click Text](Click-Text.md), [Click Image](Click-Image.md), or [If Image Click](If-Image-Click.md) when the target can move and should be recognized before input.
