# Variable Watcher

The current trigger is **Variable Watcher**. It compares a named value, checks whether it exists, or reacts when it changes.

Use a raw case-sensitive name such as `attempts` in **Variable**. The card is available in both the **Watcher** and **Variable** toolbox tabs.

See the complete [Variable Watcher guide](../Variable-Watcher.md) for the modes, missing-variable rules, and examples.
