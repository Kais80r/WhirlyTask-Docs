# Documentation screenshots

Use this folder for current screenshots made with a small, fictional test workflow. The documentation does not require access to anyone's real desktop or saved automations.

| Suggested image | What it should show |
| --- | --- |
| `sequence-editor.png` | Connected Start, condition, Then/Else branches and an ordinary action |
| `step-settings.png` | A selected step and its inspector; show the canvas-only state separately |
| `variables.png` | Starter Variable, Text/Math, Reset Variable and the configured-variable overview |
| `premade-selection.png` | Shift-drag selection and Save as Premade Block in the context menu |
| `premade-library.png` | Saved blocks, Import and `.prm` file controls |
| `recognition.png` | Smart/Pixel selection or OCR Match characters, using a fictional target |
| `watcher.png` | A trigger, its settings and its connected action chain |
| `editor-issues.png` | A deliberately invalid field and its diagnostic |

Use PNG, keep labels readable and include enough context to explain the action. Show the controls exactly as they appear in the app. Do not publish webhook URLs, private text, account names, local user paths or real captured work.

The diagrams in [../diagrams](../diagrams) are SVG illustrations, not screenshots of the running app.
